# v0.1 Research Preview Artifact Index

## Purpose

This index is the external-reader map for the current `v0.1 research preview`.
It lists the artifacts to inspect first, what each artifact supports, and what
it must not be used to claim.

Human reviewer execution is held. Gemini coverage is incomplete. Open-weight /
VLLM artifacts are a separate track. The current preview is therefore useful
for inspecting the benchmark design and early model-separation evidence, not
for citing a final human-validated leaderboard.

## Fast Reader Route

1. Read `docs/v0.1_research_preview_release_notes.md` for the release stance.
2. Read `paper/workshop_short_paper_v0.md` for the compressed external-facing
   draft.
3. Read `paper/workshop_draft_v0.md` for the longer narrative.
4. Inspect the deterministic and judged agentic summaries.
5. Inspect the matrix and canary summaries.
6. Inspect the publication-validation readiness artifacts to see why the
   leaderboard gate remains red.

## Current Readiness Summary

The current preview can claim:

- the benchmark governance stack is implemented enough to inspect end to end
- three writing families are represented in the current preview
- deterministic scoring `v2` and judge rubric `v3` are implemented
- hosted-frontier matrix artifacts show partial separation
- redacted canary artifacts show no exact reproduction among completed hosted
  working-set probes
- the human-validation batch is structurally ready
- Inspect/replay and open-weight/VLLM track boundaries are documented

The current preview cannot claim:

- human-validated benchmark status
- final leaderboard readiness
- completed Gemini coverage
- registry-complete contamination clearance
- open-weight / hosted-frontier equivalence
- publication-grade validation from LLM judge scores alone

## Refresh Commands

Before cutting a preview tag or opening a preview PR, rerun:

```bash
python3 -m compileall -q src scripts tests
PYTHONPATH=src python3 -m unittest discover -s tests -v
git diff --check
```

Refresh the readiness snapshot with the current matrix, canary, and validation
summary:

```bash
PYTHONPATH=src python3 -m life_science_paperwritingbench.cli summarize-publication-readiness \
  --matrix-summary calibration/llm_public_slice_matrix_v1/summary.json \
  --canary-summary calibration/canary_probe_v1_live_hosted_working_set/summary.json \
  --validation-summary calibration/publication_validation_v1/publication_validation_summary.json \
  --output calibration/publication_validation_v1/publication_readiness_snapshot.json
```

Expected current interpretation:

- command exits nonzero because the readiness gate is still red
- `leaderboard_gate_passed=false`
- `official_hosted_matrix_complete=false`
- `full_canary_report_ready=false`
- human agreement gates remain false
- `track_summary.missing_required_submitter_tracks` still includes
  `open_weight` until a comparable open-weight artifact exists
